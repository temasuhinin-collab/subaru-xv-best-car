# Subaru XV — лучшая машина

Небольшое Windows-приложение: при запуске показывает синюю Subaru XV 2018. Нажатие на изображение выводит надпись **«ЭТО ЛУЧШАЯ МАШИНА В МИРЕ»**; повторное нажатие скрывает её.

## Сборка через GitHub (без компиляции на своём ПК)

1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория все файлы и папку `.github` из архива: `main.js`, `index.html`, `package.json`, `assets` и `.github/workflows/build.yml`.
3. Открой вкладку **Actions** и выбери workflow **Build Windows EXE**.
4. Нажми **Run workflow**. Также сборка запускается автоматически при push в `main` или `master`.
5. Когда выполнение станет зелёным, открой запуск workflow и внизу страницы скачай артефакт **Subaru-XV-Windows-EXE**.
6. Распакуй ZIP — внутри будет переносимый `.exe`, который запускается в Windows 10/11.

## Если GitHub Actions сообщает об ошибке

Проверь, что файл `.github/workflows/build.yml` загружен именно по этому пути, а `package.json` лежит в корне репозитория.

## Локальный запуск (необязательно)

Требуется Node.js 20:
```bash
npm install
npm start
```
